# 📖 About

**Arcade Games Website** is a browser-based entertainment platform designed as a compact game hall.

The visitor enters with a name, lands in a game picker, and can move between several play modes without leaving the site. Board games, reflex games, a math challenge, and a party prompt mode share one visual language and one navigation flow.

The project is built with HTML, CSS, and JavaScript and published as a static website. It is meant to show product thinking around a multi-game interface: onboarding, selection, play, and return to the hall.

> **Tagline:** *A Persian web arcade combining board, reflex, and party games in one browser experience.*

---

# 🚀 Why This Arcade?

A single game can be a demo. A hall of games is a product.

This website was built to keep several play styles in one place:

- A clear entrance before the menu
- A visual catalog of titles
- Shared navigation back to the hall
- Local two-player boards for sitting together
- Solo modes for a short session

The result is a complete front-end arcade experience that can live on GitHub Pages and still feel like a destination.

# 🎮 The Games

| Game | Style | Experience |
|------|--------|------------|
| شطرنج | Two players, one screen | 8×8 board, piece movement, turns, restart |
| دوز | Two players, one screen | 3×3 grid, win and draw states, rematch |
| منچ | Turn-based | Dice rolls, four colors, race to the finish |
| حافظه | Solo | Flip cards, find pairs, clear the board |
| چالش ریاضی | Solo | Fresh addition questions with instant feedback |
| مار | Solo | Classic grid snake, growing score, keyboard and on-screen controls |
| جرئت یا حقیقت | Party | Random prompts from two categories |

Each title opens inside the same shell, so the hall never feels abandoned.

# 📁 Project Structure


# ❓ Frequently Asked Questions

### Do players need an account?

No. A display name is enough, and the browser can remember it.

### Do the games need a server while playing?

No. After the page loads, play happens in the browser. Hosting is only for delivering the files.

### Can two people play on the same device?

Yes. Chess and tic-tac-toe are built for two players at one screen.

### Can this be added to a resume or portfolio?

Yes. The project shows interface design, client-side game logic, RTL layout, and a multi-mode product structure in one repository.
